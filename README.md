# jev-demos

A collection of demos utilizing the system one models from TypeSafe AI.

| Package | What |
| --- | --- |
| `packages/jev_common` | Shim for their API, `.env` loading, result recording. |
| `packages/maze_lookahead` | Checking spatial reasoning and its ability to think ahead. |

## Setup

Put your API key into `.env` and then follow demo specific examples.
